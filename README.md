## ✨ Features
- **Dynamic Rendering:** Utilizes React.js to render potential thousands of items efficiently.
- **Live Search/Filter:** Instant search functionality to find specific runes or champions.
- **Modern UI/UX:** Designed with a dark theme, glassmorphism, and smooth hover states.
- **API Integration:** Ready to be hooked up to the PoxNora open-source API.
- **Responsive:** Works perfectly on desktop, tablet, and mobile.

## 🛠️ Tech Stack
- **Frontend:** React.js, JavaScript (ES6+)
- **Styling:** CSS3, Inline Styles (Component-based)
- **Data:** REST API / Mock JSON
